# P0 Evidence Inventory

The machine-readable source is [evidence-inventory.json](evidence-inventory.json).

## Baseline conclusion

The repository contains substantial bounded evidence and one large historical
run. The large run proves mechanical metabolism but remains `not_credible` for
semantic/product proof. Later entity, synthesis, joined-runtime, feedback, and
retrieval results prove their frozen populations only. They do not retroactively
repair the historical run and cannot be composed into one current-system score.

## Evidence classes

| Class | Permitted use |
| --- | --- |
| Historical integrated run | Failure reproduction, operational baseline, and regression examples |
| Bounded real-provider result | Quality evidence for the exact sealed population and runtime identity |
| Bounded database proof | Mechanical/semantic contract evidence for the exact fixture population |
| Development result | Localize a seam and guide implementation; never claim untouched generalization |
| Post-hoc rerender/rescore | Improve interpretation of saved outputs; never claim a new execution |

## P0 policy

Every later report must keep four buckets separate:

1. current coherent integrated proof;
2. current bounded component proof;
3. historical falsifying evidence; and
4. unmeasured/open-world risk.

An absent raw artifact is recorded as unavailable rather than reconstructed
from a summary. A short historical commit label is preserved as reported and
is not expanded by guessing.
